# WorkPass Web

Мобильная веб-версия WorkPass для публикации на GitHub Pages.

## Возможности

- QR-код из галереи, вход, перерыв, выход и ранний выход;
- график на месяц с плановыми и фактическими часами;
- история с фильтром по месяцу и сортировкой;
- светлая и тёмная синяя тема;
- установка на главный экран телефона и работа офлайн после первого открытия;
- индивидуальное хранение данных в браузере пользователя.

## Важно о данных

Сайт статический и не использует общий сервер. Имя, QR-код, история и настройки сохраняются только в локальном хранилище конкретного браузера. Другие посетители их не видят. Очистка данных браузера удалит историю; между устройствами автоматической синхронизации нет.

## Публикация в GitHub Pages

1. Создайте пустой репозиторий на GitHub.
2. Загрузите в него все файлы этой папки в ветку `main`.
3. Откройте `Settings → Pages` и в разделе `Build and deployment` выберите `GitHub Actions`.
4. После выполнения действия `Deploy WorkPass to GitHub Pages` адрес сайта появится в разделе Pages.

Сборка выполняется автоматически при каждом обновлении ветки `main`.

## Локальная проверка

```bash
npm install
npm run dev
```

Проверка готовой сборки:

```bash
npm run build
npm run preview
```
